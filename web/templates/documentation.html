🚀 Comenzar

Edita los archivos dentro del directorio src/ de tu proyecto. PulseDev detectará automáticamente cualquier cambio en el sistema de archivos y actualizará el navegador al instante.

src/
├── index.html       ← Punto de entrada principal
├── css/
│   └── index.css    ← Estilos de la aplicación
├── js/
│   └── index.js     ← Lógica del lado del cliente
└── assets/          ← Recursos estáticos (imágenes, fuentes)

🖥️ Comandos disponibles

pulsedev --version # Devuelve la versión instalada en el sistema

👁️ Hot Reload Automático

PulseDev monitorea el estado del proyecto utilizando primitivas nativas de fs.watch. Al detectar una modificación, realiza una verificación mediante un hash MD5 para asegurar un cambio real en el contenido, evitando falsos positivos. Las respuestas de recursos estáticos incluyen políticas dinámicas de cache busting para forzar la lectura del nuevo código.

🔌 Infraestructura WebSocket

El mecanismo de sincronización utiliza un canal de comunicación bidireccional mediante WebSockets de bajo overhead:

  1. El cliente inicializa y sostiene una conexión persistente contra el socket del servidor de desarrollo.
  2. Ante una recarga del proceso del servidor, las conexiones se finalizan de manera controlada.
  3. El script cliente captura los eventos nativos de desconexión (onclose / onerror).
  4. Se dispara una recarga forzada en el navegador web para reflejar el último estado.

📝 Arquitectura de Logs

Por omisión, las interacciones HTTP son procesadas y enviadas hacia logs/requests.log. Un subproceso en segundo plano (Worker Thread nativo) gestiona las tareas de rotación del archivo en función de la propiedad logLimit, previniendo cuellos de botella en el bucle de eventos principal.
